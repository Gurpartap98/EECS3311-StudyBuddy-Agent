StudyBuddy CLI — type/paste these IN ORDER in one session.
After each successful result → take a screenshot of that result.

Start:
  cd ~/EECS3311-StudyBuddy-Agent
  git pull
  mvn -q -DskipTests package
  java -jar target/Agent.jar cli

------------------------------------------------------------
F01 Create course
  Screenshot: "OK: Created course" + courses list with the name
------------------------------------------------------------
course EECS3311|3311|FW26
courses

>>> Copy the long course id from the courses line. Call it COURSE_ID below.

  Screenshot: "OK: Uploaded os-scheduling.txt" + materials list
------------------------------------------------------------
upload COURSE_ID data/samples/os-scheduling.txt

>>> Copy the material id from the materials line. Call it MATERIAL_ID.
